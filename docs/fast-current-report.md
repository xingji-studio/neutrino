# Fast Mode 当前测试与性能报告

更新日期：2026-11-11（Asia/Shanghai）。这是项目内唯一的当前测试与性能报告；架构和配置见 [极速模式说明](fast-mode.md)。原始记录、历次报告和本轮报告副本统一存放在 `G:\测试数据存档\neutrino-fast`。

## 当前版本与结论

本轮实现基于 **`b91fde9` 工作区**，优化验证上下文和复杂 DAG 的串行往返。实测版本以本轮归档 `docs/preflight.json` 中的源码及构建文件 SHA-256 为准；测试期间指纹保持一致。

新增真实活动 **`e4eb52d0-af58-41a3-8008-3ab5ba61340f`**：复杂 DAG 场景 `parallel_analysis`，先 Fast、后 Standard，各尝试 1 次，没有复用历史控制组、替换失败样本或降低验收标准。**Fast 完成并通过原定功能和执行协议验收；Standard 触及预算保护后中止，且缺少第四个独立只读检查员。本轮合格同期配对为 0。**

Fast 本次为 **66.82 秒、205,206 Token**，验证角色使用 **76,105 Token**。与上一版 Fast 的单次观察相比，总 Token 低 20.9%、验证 Token 低 30.9%、耗时低 22.0%。这些是跨轮描述性变化，包含模型输出、规划及供应商时延的自然波动，不能当作改动的因果效果、同期 Standard/Fast 提速比例或稳定性证明。

## 固定条件与实际验收

两侧均固定 DeepSeek / `deepseek-flash`、**Max**、上下文 1,000,000、输出 allowance 16,384、模型槽位 4。任务预算仍为 24 个 Agent、128 次模型请求、256 次工具调用、2,000,000 Token、30 分钟；原始任务、源数据、验收夹具和审批规则不变。全部请求的模型配置指纹一致，输出预算均为 16,384。

Fast 的 4 个只读检查员各自只读取指定原始文件。4 个独立源验证器分别在自己的只读作用域重新读取原文件，并独立给出明确的通过结论。协调器通过 Node 从四份原始数据重算，逐项对比四份检查员报告，遇到差异先退出，通过后才写出并回读 `answer.json`。协调器自己的独立验证器又执行了另一份 Node 检查，断言输入完整性、输出结构、全部区域数值和总计。最终主审引用了全部 **10 个当前工作/验证产物**。

原始数据哈希、40 条记录和全部数值均通过离线独立复核，结果为 `grand_units=367`、`grand_weighted=692`。Fast 缺失 usage 为 0，审批中止为 0。协议复核绑定实际工具记录和产物文件的 SHA-256，待复核项为 0；这不等同于开放任务的人工质量评审。

Standard 虽然写出了字节相同的 `answer.json`，但只有 north/east/west 三个独立只读检查员；south 由可写协调器自行读取，未满足四个独立检查员的要求。它在 95.79 秒时因本轮预算保护中止，后续独立验收未完成；已报告用量为 **137,973 Token 下界**，另有 1 次已派发审批请求取消后 usage 未知。因此保留为失败记录，不能用该耗时或 Token 下界计算双模式收益。审计的整体结果保持失败，不因 Fast 通过而改写控制组结论。

## 本轮实现

- **提前执行小型源文件读取。** 自动只读验证器仅在父产物版本准确匹配、生产作用域由运行时记录、父任务只执行成功的原生读取/列表操作时启用。最多 4 个普通文件、合计预检大小 8,192 字节，拒绝越界及符号链接逃逸；不适用时沿用原工具循环。每次读取仍重新执行，在验证器自己的作用域经过原权限、审批、取消、预算和证据记录流程。它提供源数据，不提供验收结论。本轮 4 次新读取均发生在各验证器首个模型请求之前，4 个验证器各用 1 次 Max 请求独立完成判断。
- **无损合并重复版本哈希。** 只将运行时生成的 `input_versions` 中、与当前上下文版本一致的重复 SHA-256 提取为共享表；完整字典及解释更短时才使用。存储产物、版本校验、用户正文、工具参数、原始证据和全部结论/假设不改写。可精确展开恢复。历史元数据片段的离线字节核验为 26,491 → 24,938 字节（含字典），不将字节差额当作模型 Token 收益。
- **协调验证器直接获得完整上游报告。** 仅预载父任务已声明依赖、记录版本匹配、处于授权依赖链中的工作产物，整组最多 12,000 字节；超过上限时通过原精确证据工具读取，报告不截断。索引区分报告已内联与是否验证通过；所有独立验证结果继续保留和可读取。

本轮仍有协调验证器单独执行 `ls/cat` 后再运行 Node 断言的开销，产生了额外审批；最终主审仍需约 10 秒。后续可继续改善同一作用域内的必要操作组合和上下文表示，不能省略独立检查或把旧结果当作新文件状态。
