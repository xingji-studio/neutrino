# 极速模式性能与验证报告

本文件保留初始实现的历史活动。最新 Token、DAG 与审批/目录优化后的四场景三轮真实对照见 [fast-efficiency-v3-comparison.md](fast-efficiency-v3-comparison.md)：24 次新运行，Fast 完整验收 12/12、Standard 9/12，9 对合格配对均更快，4 对减少 Token。复杂 DAG 规划明显缩短，但独立验证 Token 未下降，且仅 1 对完整合格对照；尚未确认跨任务普遍节省 Token 或 50% 缩时目标。前两版试验、失败与修复说明见 [fast-efficiency-optimization.md](fast-efficiency-optimization.md)。后文的 incomplete/HTTP 402 属于历史活动，不代表当前模型不可用。

本报告由机器可读实测结果生成。真实模型活动状态：`incomplete`。模型：`DeepSeek/deepseek-flash`，推理档位：`Max`。两种模式使用同一模型配置、任务要求、必要检查及账户配额。

**50% 端到端缩时目标：尚未证实达到。** 有效成功对照 7 类，合计时间节省 -76.4%（负值表示变慢）。

每类每模式仅运行 1 次；单样本均值与中位数相同。P95 需要更多重复样本，本次标记为未测。失败、中断或等待审批而未完成的样本不能用于宣称加速。

部分 Standard 数据复用已完成的基线，以避免重复付费调用。复用前校验了相同模型/档位、原始测试输入、30 个相关编译模块与四份原提示词的指纹；原样本均在旧时限内成功完成。原始出处及校验信息保存在 JSON 的 standard_baseline/reused_from 字段中。旧构建的 Fast 失败样本另存 fast-live-before-scope-fix.json，没有被伪装成成功或抹去。

**外部阻塞：供应商返回 HTTP 402 / Insufficient Balance（余额不足）。** 前七类已完成有效对照；强顺序依赖任务的 Fast 在执行中中断，补充四路分析没有完成对照。没有充值、换模型或降低推理档位来绕过此限制。失败行的时间是截至中断的经历时间，并非任务完成时间。

真实调用使用生产默认的 30 分钟时限。第九类是补充的明确可并行负载：四路受限只读资料检查，协调者用 Node 独立重算并验证全部原始资料；同一要求应用于两种模式。前八类是小型受控任务，并不代表大型开放任务。单次顺序调用与复用基线也会受到服务延迟变化影响，不能替代随机化重复实验。

本组 Fast 模型请求合计 287 次，Standard 为 250 次；Fast 调度累计 36.88 毫秒。模型请求计数来自共享 TaskRuntime；阶段指标中的 requests 是逻辑轮次，口径不同。

关键路径分析：没有独立分支的任务必须顺序执行；额外增加并发槽位不能缩短真实依赖。小任务的独立规划、局部验证与最终审查会增加固定模型往返开销。可从原始数据中的 `model_requests`、工作任务数、验证节点和审批等待识别这些情况；若调度开销和工具等待很小而模型轮次明显增加，可以推断瓶颈主要在模型请求和验证依赖链，而不是 DAG 扫描。该推断不是直接测得的模型纯推理时间。

任意 shell 任务当前使用独占工作区范围，包含命令的分支可能因此串行；显式只读分支和不相交的限定路径编辑才可并行。单次改善也可能来自模型执行路径或服务延迟的变化；只有一个工作节点的样本尤其不能用来证明并发的因果收益。

实现已采用的优化包括：流式启动、依赖满足后立即解锁、复用真实工具证据、限定 Worker 任务范围、在原上下文纠正输出格式、避免重放写入，以及让审批模型也受同一推理池限制。未降低模型、推理档位、输出预算或必要检查。

## 未完成的验收与限制

- 尚不能据此宣称一般复杂任务的 50% 缩时目标已经实现。
- 统计可靠的 P95、多轮随机化顺序、开放式答案人工评审、公网多站点检索和大型项目开发尚未测；本组为可重复的本地资料、逻辑和小型代码任务。
- 供应商缓存计费 Token 没有由现有接口可靠提供，标记为未知；本地上下文缓存命中不代表供应商计费减免。
- 初次中断记录保存在 `fast-live-interrupted.json`，其中失败/超时任务不是成功的速度对照。

后续待验证的优化包括：让 Planner 将简单任务合并为更少的工作节点，避免另建与隐式验证重复的审查任务；在保留独立验证和最终审查的前提下，让不相交的编辑先并行、再由协调者运行必要测试。任意 shell 的真正并行需要可验证的文件系统隔离，当前未实现；不能仅放松访问范围来换取速度。
