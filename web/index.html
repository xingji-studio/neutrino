Pro orchestration

Every Pro task is planned first. All roles share the regular provider configuration. Image generation is reserved.

Edit role models, intensity and context windows in ~/.neutrino/pro/model.json. Default delegation depth: 10.

Conversation and approvals

Auto-compress at 80% of this model's context window. Default: 1,000,000 tokens.

Safety determines automatic approval; task relevance only blocks unanimously confirmed, extreme mismatches. Delete-class automatic approval also requires this setting.

Background residency

Off by default. Changes take effect immediately, including for running browser tasks. The regular and Pro workspaces share this setting. Terminal conversations still end when the terminal closes.

Web access

Binds the Web console to 0.0.0.0 so other devices on your network can open it, like --lan. Takes effect immediately; turning it off returns the console to 127.0.0.1. Keep the Web password on: anyone who can reach this port can drive the agent.

The password is permanent and survives restarts. Default: 114514. Saving a new password signs out other browsers.

Updates

Neutrino checks npm for new releases every 30 minutes. Both workspaces share that check.
