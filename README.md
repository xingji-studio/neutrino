## 什么是 Neutrino ？

Neutrino 是由 XINGJI 工作室开发的一款跨生态跨平台的全新架构 Agent。

## Neutrino 有什么特点？

- 提供 Web 控制台，对手机端进行特别优化，提供与 CLI 界面**一样甚至更好**的操作体验。
- Pro 模式 使用全新自研 “站中间串两边” 架构，把任务分割给各个最适合的模型，降低成本并提升一次通过率，免去繁杂的描述和拆分挑选，**真正做到一句话一次性做到最好**！
- OpenCode 的思考强度切换简直是一坨史，但Neutrino不存在这个问题。**你想要什么强度就用什么强度。**
- 配置文件条目清晰，想怎么用就怎么用，相比于 OpenCode 更加方便。
- 更严谨更方便的自动审批系统，**一键切换**，多智能体评审，保证数据安全。
- 超级轻量，总代码量仅 3 万行。
- 兼容 ClaudeCode、OpenCode、Codex 等多种 Agent 的对话格式，无缝迁移。
- 1000 万以内最好的 Agent！（绝对没有嘲讽某公司的意思）

## 相比于 OpenCode 的优势

- 可以方便自由地随意调整思考强度。
- 提供更好的 Web 控制台，为手机端特别优化，不管什么手机什么设备，无需下载随时随地只要有网就能远控！
- 进行特殊优化，**更省钱！**（OpenCode 用啥都贵）
- 更简单严谨的自动审批系统，解放双手的同时保证你的数据安全，全自动审批一切命令（可以在设置中调整，要求高危命令人工审批），无需人工干涉。
- 更好的自动重试系统。
- 我们是小团队，你的建议我们全部都能收到！
- Pro 模式真正做到一句话一次性做到最好！目前主流 Agent **全部** 没有这个功能！（因为主流 Agent 基本都是 AI 厂商的，总不能自家 Agent 用自己竞争对手的东西吧）
- 配置文件简洁易懂，想咋改就咋改。

## 安装方式

npm 一键安装：

``` bash
npm install -g @xingjisoft/neutrino
```

## 使用小技巧

- Web 控制台配合 Tailscale 等软件，可以直接实现外网安全远控！而且无需下载，打开即用！
- 支持后台常驻（默认关闭）：在 Web 控制台或终端设置中切换后立即生效，开启时关闭终端也不会中断已开始的浏览器任务。也可以用 `neutrino background start|stop|status|open` 管理后台控制台。
